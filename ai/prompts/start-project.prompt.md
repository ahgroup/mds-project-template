# Prompt: Start a Project From This Template

Use this prompt when beginning a new project from the template.

```text
Please review this repository as a reproducible data-analysis project. The
default example uses R and Quarto, but the project may add other languages.
Read README.md, AGENTS.md, project-metadata.yml, and data/data-use-notes.md.
Also read USAGE.md for the manual run order.

First, summarize the project structure and expected workflow. Then identify the
minimum set of project-specific edits needed before analysis begins, including
README updates, data-use documentation, package needs, and reproducibility checks.

Do not modify files yet. Do not inspect private or sensitive data unless
data/data-use-notes.md explicitly says that AI tools may inspect it.
```
